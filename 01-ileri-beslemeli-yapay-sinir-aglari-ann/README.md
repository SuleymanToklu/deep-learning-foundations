# İleri Beslemeli Yapay Sinir Ağları (ANN) ve Keras Sequential API

Bu modül; derin öğrenmeye ilk adımı temsil eden çok katmanlı algılayıcı (Multilayer Perceptron - MLP) mimarilerini inceler. Katmanların (Dense) ardışık olarak bağlanması, doğrusal olmayan aktivasyon fonksiyonları (ReLU) ve optimizasyon algoritmaları (Adam) uygulamalı olarak ele alınır.

- ReLU aktivasyonu: $f(x) = \max(0, x)$
